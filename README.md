# LISTO

Concierge de eventos: escribís lo que querés festejar y LISTO lo ordena y te muestra propuestas.

> Versión demo: las propuestas son de ejemplo. No hay proveedores, precios ni disponibilidad reales.

## Archivos

- `index.html`: la estructura de las tres pantallas (tu idea, detalles, propuestas).
- `styles.css`: el diseño (colores, tipografías y adaptación a celular).
- `app.js`: la lógica. Interpreta el texto, deja editar los datos y arma las 3 propuestas de ejemplo.

## Verla online con GitHub Pages (gratis)

1. En GitHub, entrá al repositorio y andá a **Settings** → **Pages**.
2. En **Source** elegí **Deploy from a branch**.
3. En **Branch** elegí la rama donde están estos archivos (por ejemplo `main`) y la carpeta **/ (root)**. Tocá **Save**.
4. Esperá 1 o 2 minutos y recargá la página: arriba vas a ver el link, con esta forma:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

## Verla en tu computadora

Descargá los archivos y abrí `index.html` con doble clic.
